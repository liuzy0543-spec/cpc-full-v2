# benchmark 结果（embedding 方法与基线）

这份文件回答三个问题：**排第几、比基线强多少、哪些数不能信**。

- 主结果：3,857 细胞 / 54 化合物（BBBC022 板 20585 的单细胞裁剪）
- 校准结果：352 细胞子集（12 化合物 × 16 + 8 个 mock 孔 × 20）
- 指标定义与打分脚本：`scripts/embedding_benchmark/score_benchmark.py`

> 本树 `demo/embeddings/` 里那 8 个细胞的小例子**只证明链路和调度正确**，
> 不产生下表的统计结论。

## 3. 结论

1. **排序稳定**：两轮数据上都是 `cellclip` > `ca_mae` > `deepprofiler` > 其余，
   这是唯一能跨子集复现的结论。
2. **只有两个方法明显超过基线**：完整一轮里 `cellclip` 比原始像素高
   8.3 个 mAP_z 点，`ca_mae` 高 5.8 个点；
   `deepprofiler` 只高 1.8 个点，等于"嵌入没比原始外观多给多少信息"。
3. **`o2vae` 在随机水平**：mAP_z 0.0471，随机基线 0.0450，
   mock AUC_z 0.5054 ≈ 0.5。它吃的是**核剪影**，而官方权重训练于细胞剪影，
   属域外推断，这个数**不能**读成 O2-VAE 的性能。
4. **silhouette 全为负**：这批数据上没有任何方法形成"按化合物可分"的簇。
   最差的是 `morphogenie`（-0.7161）。
5. **有效秩差别很大**：最低的 `morphogenie` 只有 1.0，意味着距离
   基本由一两个维度决定；最高的 `deepprofiler` 达到 34.7，才用上了较多维度。

## 4. 这些数字不能这么用

| 限制 | 后果 |
|---|---|
| **一个化合物只有一个孔** | 孔/视野外观与化学性质混在一起，绝对分数被抬高；能信的是"相对原始像素基线的差" |
| 一个化合物一个浓度 | 无法做剂量反应 |
| `unidino` / `dinocells` / `morphogenie` 是本地自训替身 | 名次只说明接口跑通，**不是**这些方法的发表性能 |
| mock 细胞没有化合物名 | 被当作一个名为 `nan` 的伪化合物参与检索，kNN/mAP 因此偏高 |
| 2 行数据的 pycytominer 链 | demo 里 06–09 的输出不具统计意义 |

## 5. 怎么复现

```bash
# 目录需要 meta.csv + emb_<method>.npy + cells_dp.npy（原始像素基线）
python scripts/embedding_benchmark/score_benchmark.py \
    --cells-dir <你的目录> --profile v3 --output scores.json
```

本文件里的数字对应 `scores_full_run.json` 与 `scores_subset.json`；
两份 JSON 也在同目录，字段与脚本输出一致。
